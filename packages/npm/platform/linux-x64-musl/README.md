# @codevachon/mysql-ultralight-linux-x64-musl

The `mysql-ultralight` binary for `linux-x64-musl`, built from `x86_64-unknown-linux-musl`.

Installed automatically as an optional dependency of
[`@codevachon/mysql-ultralight`](https://www.npmjs.com/package/@codevachon/mysql-ultralight).
Nothing should depend on it directly.
